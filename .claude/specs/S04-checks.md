# S04: Checks (scene.v1 → check.v1)

- **Owner:** Siva
- **Status:** todo
- **Depends on:** S03
- **Target:** 2:00
- **Models:** none. Checks are generated by code, NEVER by an LLM.

## Goal
Turn a scene into 20–60 falsifiable yes/no or choice questions, each with an expected answer derived from geometry, and only where the geometry is unambiguous.

## Files
- `godshot/checks.py`
- `tests/test_checks.py`

## Spec
- `make_checks(scene, sample_ts: list[float] | None = None, frames_dir: Path) -> list[CheckV1]`. Default sample times: every 1.0 s from 0.5 to duration−0.5. Pairs: (t, t+1.5) for motion.
- Templates (fill `{}` with `visual_description`):

| Template | Input | Type | Emit only if (abstain margins) | Instruction |
|---|---|---|---|---|
| VISIBLE | frame | noul | \|bearing\| < hfov/2 − 8° | "Look at this single film frame. Is {obj} visible, even partly, anywhere in the image?" |
| NOT_VISIBLE | frame | noul, expected=false | \|bearing\| > hfov/2 + 8° | same wording |
| SIDE_LEFT / SIDE_RIGHT | frame | noul | visible and \|bearing\| > 6° | "Is {obj} in the LEFT half of the image?" / RIGHT |
| A_LEFT_OF_B | frame | noul | both visible, bearing gap > 8° | "In this image, is {a} further to the left than {b}?" |
| CLOSER | frame | choice {a_first, b_second, other} | both visible, distance ratio > 1.3 | "Which of these is closer to the camera in this frame?" |
| TOWARD | pair | noul | actor distance changes > 15% | "Image 1 is at {t0}, Image 2 is at {t1}, same shot. Did {actor} get closer to the camera between Image 1 and Image 2?" |
| PAN | pair | choice {pan_left, pan_right, other} | \|Δyaw\| > 10° | "...How did the camera rotate between them?" pan_left = "Camera turned to its left (scene slides right)" |
| DOLLY | pair | choice {dolly_in, dolly_out, other} | forward move > 15% of mean scene distance | "...Did the camera physically move toward or away from the scene?" |

- **Mirrored controls:** for 20% of SIDE checks, also emit the opposite-side question (expected=false). Tag with `control: true` (optional field; add it to contracts.md changelog).
- Stable `check_id`s: `sha1(template, entities, t)[:8]`, so checks can be compared across rounds.
- Cap ~60 checks per clip; prioritize motion checks, then SIDE, then the rest.
- `frames_needed(checks) -> list[float]` so S01 can extract them up front.

## Acceptance criteria
- [ ] On the mock scene: produces 20–60 checks covering every template that applies; expectations match hand-reasoning on 5 spot-checked items.
- [ ] No check is emitted inside its abstain margin (property test with random poses).
- [ ] Instructions are full sentences and never mention ids (the Decisions model never sees question keys).
