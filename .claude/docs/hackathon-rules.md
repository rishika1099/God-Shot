# Hackathon rules that affect us (Gemini 4 NYC, Nov 21 2026)

- **Public repo required.** Push before submission.
- **New work only.** Everything is built today; the demo shows only what we built today. Our git history is our proof, so commit often with clear messages.
- **Team size 1–4.** We are 4: Rishika, Prajesh, Akash, Siva.
- **Banned:** using code, data or assets we don't have rights to → open-licensed clips only, credits in `eval/CREDITS.md`, consent forms for venue footage.
- **Banned project types we must not resemble:** Streamlit apps (→ we use FastAPI + HTML), image analyzers (→ we pitch it as scene reconstruction + generation), basic RAG, dashboards as the main feature.
- **Element 119 track asks:**
  - What's the hardest input, and does it hold up?
  - What does raw video give us that text would lose?
  - How far did we push before it broke, and what did we change?
  - Not allowed: demos that only run on scripted inputs; evals made only of examples the team wrote to pass → CameraBench + clips filmed by non-team people.
- **Required API:** use the Decisions API (we do, as the verifier).
- **Prize to target:** placement in Element 119. The 5 Sigma eval style strengthens our case.
